# Geely Sound

Музыкальный плеер для штатного ГУ Geely EX5 EM-i и других ГУ Geely/Belgee
на Android 9. Одно приложение: «Звук» и «Яндекс Музыка», эфирное
Яндекс.Радио, аудиокниги, музыка с флешки, поиск, избранное и история по
каждому сервису. Управление с кнопок руля, приборной панели и уведомления,
автозапуск при включении машины.

Подстраивается под экран — 2560×1600, 720p и узкие панели. Интерфейс на русском.

## Установка и обновление

1. Скачайте APK последней версии из раздела
   [Releases](https://github.com/Aowa048/geely-sound-updates/releases/latest).
2. Разрешите установку приложений из неизвестных источников и установите файл.

Дальше обновления приходят прямо в машину: приложение само сообщает о новой
версии, скачивает и устанавливает её. Вход в аккаунты и настройки сохраняются.
